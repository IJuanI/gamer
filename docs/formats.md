# Social Media Banner Formats — Quick Reference

All dimensions validated against 2026 platform specifications.

## Instagram Story

| Property | Value |
|---|---|
| **Dimensions** | 1080 × 1920 px |
| **Aspect ratio** | 9:16 |
| **Safe zone** | 250px top, 250px bottom, 60px sides |
| **Max file size** | 30 MB (image) |
| **Formats** | JPG, PNG, HEIC |
| **Display time** | 7 seconds (image) |
| **Notes** | App overlays profile info top, action buttons bottom |

**Sources**: [SocialSizes.io](https://socialsizes.io/instagram-stories-size/), [Buffer](https://buffer.com/resources/instagram-image-size/), [Postfast](https://postfa.st/sizes/instagram/stories)

## Instagram Feed — Tall (3:4)

| Property | Value |
|---|---|
| **Dimensions** | 1080 × 1440 px |
| **Aspect ratio** | 3:4 |
| **Safe zone** | 40px all sides |
| **Max file size** | 30 MB |
| **Formats** | JPG, PNG |
| **Notes** | Matches profile grid preview exactly — no cropping on grid view. New format supported since late 2025. |

**Sources**: [Inro.social](https://www.inro.social/blog/instagram-post-size), [Postfast](https://postfa.st/sizes/instagram/feed)

## Instagram Feed — Post (4:5)

| Property | Value |
|---|---|
| **Dimensions** | 1080 × 1350 px |
| **Aspect ratio** | 4:5 |
| **Safe zone** | 40px all sides |
| **Max file size** | 30 MB |
| **Formats** | JPG, PNG |
| **Notes** | Classic maximum vertical format. Gets slightly cropped on the 3:4 profile grid (top/bottom). |

**Sources**: [Buffer](https://buffer.com/resources/instagram-image-size/), [PixExact](https://www.pixexact.com/blog/instagram-post-size-guide)

## WhatsApp Status

| Property | Value |
|---|---|
| **Dimensions** | 1080 × 1920 px |
| **Aspect ratio** | 9:16 |
| **Safe zone** | 120px top, 200px bottom, 60px sides |
| **Max file size** | 16 MB |
| **Formats** | JPG, PNG |
| **Display time** | 30 seconds (image status) |
| **Notes** | Username overlay at top, reply button at bottom. Keep critical content in center 1080×1600 area. |

**Sources**: [Moda](https://moda.app/resources/sizes/whatsapp-status), [Chatarmin](https://chatarmin.com/en/blog/whats-app-image-size-guide), [PictureSizes](https://picturesizes.com/specs/social-media/whatsapp/)
